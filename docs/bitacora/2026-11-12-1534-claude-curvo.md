# «Curvo»: el sistema tal como está, con las esquinas más redondas

## Pedido del dueño
Tras el reel «Glassy Dashboard V31» se le mostró el lote por columnas. Aclaró: «Me refiero que usemos tal como está actualmente pero con lados curvos como en el video, en el sistema completo». Es decir: NO cambiar pantallas; solo curvar las esquinas de todo el taller.

## Qué se hizo
- Archivo nuevo `bc-curvo.js` (`?v=20261112-cu1`), cargado en el `<head>` de `taller.html` después de los estilos y sin `defer`, para que la página se pinte ya curva (sin salto).
- Recorre las hojas de estilo del taller y sube cada `border-radius` en px según una tabla: 4–6 → 10, 7–9 → 14, 10–12 → 18, 13–16 → 24, 17–22 → 28, más → 32. Menos de 4 px, píldoras (≥100 px), porcentajes y esquinas en 0 quedan igual.
- Los estilos escritos dentro de las etiquetas (`style="border-radius:8px"`) se cubren con reglas por atributo (solo cuando es un único valor; «12px 12px 0 0» no se toca).
- Las capas que agregan estilos después (pistola, ficha al costado, etc.) también se redondean (observador).
- No se tocan: casillas, interruptores, barras finas, fotos de equipos, lo que se imprime (`@media print`) ni las ventanas de impresión.
- No cambia colores, tamaños, textos ni funciones.
- Apagar: `localStorage.bc_curvo_off='1'` o `window.BC_CURVO=false`.
