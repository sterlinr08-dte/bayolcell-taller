# Captura guiada — vista de prueba

Son datos ficticios, con ventas simuladas y un alquiler de ejemplo. No representan cifras reales de Bayol Cell. Capturas con Chromium, interfaz real del módulo y estilos de taller.html.

[Celular, 390 px](celular.png) · [PC, 1280 px](pc.png)

| Lo que hace su asistente | Lo que hace el sistema |
|---|---|
| Escribe el gasto y escoge el estado | Cuenta confirmados y pendientes |
| Adjunta foto/PDF o escribe una nota | Conserva el soporte con acceso privado |
| Cambia un monto | Lo vuelve a marcar Por revisar |
| Copia el mes anterior | Deja los montos como estimados, sin repetir recibos |

Sigue siendo una propuesta sin publicar. La asistente necesitará el permiso de Contabilidad existente. No se ha llenado noviembre con importes reales. Cuando termine la captura, la contadora revisa el reporte: el sistema no certifica ni bloquea el cierre.
